# Changelog

[Português (Brasil)](CHANGELOG.pt-BR.md)

## From the first release (`v1.0`) to `v1.1.0-rc.1`

- Added a standalone Windows program with modern interface, asset library and simplified Settings.
- Hardware-GPU model/texture previews with orbit, pan, zoom and camera reset.
- SSG/folder and BNK/PCK bank browsing, search, filters, selection and asset information.
- Texture preview/PNG export and audio/video preview/extraction through optional external dependencies.
- Selected/all-source and installation-batch extraction with progress, cancellation and no-overwrite safeguards.
- FBX, `.blend` and GLB model export through external Blender, resolved materials/textures and output verification.
- Portuguese/English interface, rewritten complete README/tutorial, refreshed screenshots and dependency links.
- Packaging cleanup removes unnecessary DLLs and includes third-party notices; official Visual C++ x64 is an external prerequisite.

**Prerelease:** deforming rigs, native game-format writing and in-game compatibility remain unapproved. Experimental addons are not distributed in this release. [Limitations](docs/RELEASE-AUDIT.md).
